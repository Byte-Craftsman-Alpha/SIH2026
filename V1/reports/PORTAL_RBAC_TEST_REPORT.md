# End-to-End Test Report: Doctor and Admin Portal Separation

## Test Suite Overview

An automated UI test suite using **Playwright** has been developed to verify the role-based access control (RBAC), UI dynamic rendering, and redirection logic for the `admin` and `doctor` roles.

- **Test Script Path:** `V1/backend/test_portal.py`
- **Screenshot Artifacts Directory:** `V1/reports/screenshots/`

### Test Scenarios Executed

| Scenario | Role | Action | Expected Result | Pass/Fail |
|----------|------|--------|-----------------|-----------|
| 1. Doctor Login | Doctor | Login with Doctor credentials | Redirects to `/portal/queue` | **PASS** |
| 2. Doctor UI | Doctor | View Dashboard | Displays "Dr. Rajesh Sharma" and hides "Audit & DPDP" | **PASS** |
| 3. Doctor Permissions | Doctor | Force access to `/portal/admin` | Denied (403 Forbidden) | **PASS** |
| 4. Admin Login | Admin | Login with Admin credentials | Redirects to `/portal/admin` | **PASS** |
| 5. Admin UI | Admin | View Dashboard | Displays Admin badge, exposes Audit panel | **PASS** |
